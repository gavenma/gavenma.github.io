title: "VAMO: Efficient Large-Scale Nonconvex Optimization via Adaptive Zeroth Order Variance Reduction"
collection: publications
excerpt: 'Jiahe Chen, Ziye Ma'
date: 2025-05-20
venue: 'Preprint.'
paperurl: 'https://arxiv.org/pdf/2505.13954'
abstract: >-
  We introduce VAMO, a variance-reduced mixed-gradient optimizer that combines full-batch zeroth-order gradients with mini-batch stochastic updates. Its hybrid estimator achieves a dimension-agnostic convergence rate while using less dynamic memory than many first-order baselines. Neural-network training and LLM fine-tuning experiments show strong performance with a smaller memory footprint.
